# Gra Zwiadowca

Przeglądarkowa gra zręcznościowa na strzelnicy w Redmont: strzelanie z łuku, rzut nożem, znikające tarcze, kalkary, konny Temudżein i wargale. 4 poziomy po 6 plansz.

Fanowska gra niekomercyjna inspirowana serią „Zwiadowcy” Johna Flanagana. Nie jest związana z autorem ani wydawcą.

## Uruchomienie

Wystarczy otworzyć `index.html` w przeglądarce. Projekt nie wymaga budowania ani serwera.

## Publikacja na GitHub Pages

1. Wypchnij repozytorium na GitHuba.
2. W repozytorium: **Settings → Pages → Build and deployment → Deploy from a branch**, gałąź `main`, folder `/ (root)`.
3. Gra będzie dostępna pod adresem `https://<użytkownik>.github.io/<repozytorium>/`.

## Pliki

- `index.html` – gra
- `wyniki.html` – tabela wyników (zapisywana w `localStorage` przeglądarki)
- `favicon.svg` – ikona strony
- `fonts/` – lokalne fonty Cinzel i EB Garamond (SIL Open Font License)
